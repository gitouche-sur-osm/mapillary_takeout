# mapillary takeout

**This script is no longer maintained. Please use the new version for the
Mapillary API v4:**

**<https://download.bbbike.org/src/mapillary-takeout-v4/>**

It downloads your own Mapillary images in full resolution for a local backup,
with EXIF restored, and can be run again at any time to fetch only new images.

## Legacy v3

This script was written for the Mapillary API v3, running on the old Mapillary
infrastructure on Amazon AWS. In June 2021 Mapillary switched to the API v4 on
Meta (Facebook) infrastructure, and this script stopped working.

The new version uses different file names, so a backup made with this script
is not recognized as already downloaded.

This repository is archived (read-only). The old documentation is in
[README-v3.md](README-v3.md).
